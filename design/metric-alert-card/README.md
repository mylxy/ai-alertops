# 指标告警状态卡设计

2026-10-05 按用户要求统一为三个主状态：**待处理、处理中、已恢复**。首条备注保存成功表示开始跟进；恢复前允许继续追加备注；匹配本轮的监控恢复事件到达后变为已恢复，禁止再添加备注。

## 状态和操作

| 条件 | 卡片状态 | 标题颜色 | 操作 |
| --- | --- | --- | --- |
| 监控仍告警，未保存备注 | 待处理 | 红色 | 添加备注 |
| 监控仍告警，已保存备注 | 处理中 | 琥珀橙 | 继续追加备注 |
| 监控确认恢复 | 已恢复 | 绿色 | 历史记录只读，禁止新增备注 |

来源监控仍使用 `firing/resolved`。卡片的处理中表示有人跟进，不代表指标已恢复。无需认领，不增加独立的“标记处理中”按钮，也不提供人工关闭指标告警的入口。未提交的草稿、取消和空白内容不改变状态。

备注展示最近三条并保留完整历史入口。备注编辑时展示输入框、提交和取消；提交成功收起输入框，恢复添加入口。已恢复时即使先前打开了编辑框，也必须拒绝后到提交。

## 卡片与 H5 共用视觉

H5 对照官方模板的字段顺序和版式展示，不添加趋势图、柱形图、插图或额外指标。

1. 阶段色标题栏：“指标告警 · 状态”，下一行显示问题标题。
2. 对象信息：环境或项目与实例。
3. 浅灰信息块：指标数值、阈值和持续条件、首次/最近接收或恢复时间、持续时长。
4. 指标键及必要维度；监控状态说明。
5. 有备注时展示备注信息块与处理记录入口。
6. 未恢复时展示“添加备注”；输入框仅编辑时展开。

| 参数 | 规格 |
| --- | --- |
| 状态标题、问题标题 | 12 px / 19 px |
| 头部内边距 | 左右 16 px，上 13 px，下 14 px |
| 正文内边距 | 左右 16 px，上 12 px |
| 浅灰信息块 | `#F5F7FA`；左右 12 px、上下 10 px；圆角 8 px |
| 红 / 橙 / 绿头部 | `#C73E47` / `#AC6817` / `#21865C` |
| 深色头部 | `#A83139` / `#8D5117` / `#1A6D4B` |
| 指标值 | 28 px；异常时使用平台告警强调色，恢复后使用恢复色 |
| 按钮 | 沿用钉钉原生样式；H5 对照 8.0 预览使用浅灰圆角按钮、蓝色主操作文字 |

日志卡与指标卡保留各自模板的信息顺序；H5 和群内预览复用同一份卡片渲染。H5 外层仅承担分类、计数和列表导航，不改变卡片本身的信息结构。

## 复现和验证

在仓库根目录运行：

```bash
python3 design/metric-alert-card/build_preview.py
node design/metric-alert-card/verify_preview.mjs
```

生成器默认读取仓库内已保留的官方组件样例，无需下载或安装依赖，也可传入另一个官方样例路径。输出 `metric-alert-card.json` 为设计器导入封装，不是生产发送参数。模板共 35 个原生组件；所有按钮只做本地模拟更新。

本次已在官方设计器验证：初始待处理、首条备注后处理中、第二条备注继续追加、模拟监控恢复后已恢复且无备注入口；保存并重新加载后默认状态为待处理。H5 已移除模拟走势图，并按此处结构及日志模板对齐。

“模拟监控恢复”属于设计演示控件；正式卡片不包含该按钮。时间、身份、数值和备注均为测试数据，当前没有业务后端持久化，也未执行模板发布。

已向“告警平台卡片交互测试”群投放指标卡、日志卡及本机 H5 预览入口，接口均返回成功，用户确认指标卡正文和按钮可见。群内按钮尚未由代理完成点击验证；设计器与 H5 的检查不能替代跨端联调。具体范围见 [preview-verification.json](preview-verification.json)。本机 H5 链接不支持直接在手机访问，群卡和 H5 暂未连接同一业务后端。
