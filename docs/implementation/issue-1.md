## 推荐默认与必要假设

- Go 标准库 HTTP + MySQL 驱动，Vue 3 + Vite，不引入消息中间件/通用 RBAC。单企业，单服务器 Docker；宿主进程之间使用数据库锁与本机调度文件锁。
- 普通用户查全部告警；群写需实时成员验证。成员验证失败不沿用无限期缓存。首次管理员由部署配置指定，最后一个 ACTIVE/ADMIN 不能被配置移除。
- 统一服务器毫秒时间、上海显示时区；指标 cycle_key 保留纳秒。JSON ID 是字符串。游标每页50、最近事件100，处理记录与 MR 集合完整返回。
- Codeup 基于组织+数字仓库 ID+仓库内 localId；Hook 只是持久提示，权威查询会证明最新 MERGE_SOURCE patch 和合并提交，不能用本地记录替代提供方证据。
- 一次任务可有多个 MR。卡片展示前八条并链接完整 H5；这是卡片可读性边界，不是业务数量上限。每仓库最终声明必要数量1–100作为输入容量约束。
- 项目三个预置目录各为普通独立 clone。为避免宿主执行任务写入的配置，宿主只读探测拒绝执行扩展/include/过滤器、共享 Git 元数据及子模块；需要的子模块作为独立项目仓库登记。业务构建依赖由固定项目镜像提供。
- 任务执行采用 Codex API 凭据环境引用。宿主上已经登录的 Codex APP 会话和重置额度不自动传入 Docker；模型凭据与计费方式需真实环境验证，不把桌面额度当成容器密钥。
- 未验证出可靠钉钉未知写入核对接口前，未知消息保守挂起单目标。其他卡片和业务保存继续；这种退化行为清楚展示待核对，不能宣称全部消息自动最终一致。
- `-demo` 只监听回环，身份与外部消息替身只用于隔离验证。模拟外部消息内存重启后不保留，平台数据库历史仍保留。生产部署不得开启演示入口。
