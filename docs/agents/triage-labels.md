# 分诊标签

下表将技能使用的五个标准分诊角色映射到本仓库的实际标签。

| 标准角色 | 实际标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可交给代理实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能要求应用某个分诊角色时，使用表中的实际标签。
如需沿用其他标签名称，修改“实际标签”列，保留标准角色不变。
